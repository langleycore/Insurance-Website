# Virginia P&C Insurance Exam Prep

A mobile-optimized web application for studying for the Virginia Property & Casualty Insurance licensing exam.

## Features

### Practice Test Mode
- 30 comprehensive multiple-choice questions
- Instant feedback after each answer
- Detailed explanations for every question
- Score tracking throughout the test
- Coverage of Virginia-specific regulations and general P&C principles

### Flashcard Mode
- 50 essential insurance terms and definitions
- Interactive flip animation
- Progress tracking
- Organized by category

## Technologies

- React 19
- TypeScript
- Vite
- Mobile-first responsive design
- iPhone optimized

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Usage

The app works perfectly on iPhone browsers and can be added to your home screen for a native app-like experience:

1. Open the app in Safari on your iPhone
2. Tap the Share button
3. Select "Add to Home Screen"
4. The app will now appear as an icon on your home screen
